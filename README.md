# 컨트롤타워

시스템의 현황, 사용법, 자료 흐름, 점검과 다음 조치를 한곳에서 관리하는 개인 운영 지도입니다.

**접속:** https://gjdnddd.github.io/control-tower/

## 화면

- 전체 현황: 시스템 수, 사용 상태, 확인할 문제, 즐겨찾기와 최근 변경.
- 시스템 목록: 검색과 분야·유형·사용 상태·점검 상태 필터, 카드/목록 보기.
- 사용법 위키: 준비·실행·종료·문제 해결 문서와 편집.
- 연결 관계: 작업 흐름별 관계도, 시스템 상세 이동과 관계 등록·편집.
- 점검·다음 조치: 근거, 우선순위, 처리 상태와 후속 작업.
- 변경 기록: 기존 검토와 기기별 편집 이력.

사용 상태와 점검 상태는 서로 독립적입니다. 문서에 적힌 과거 운영과 실제 최신 점검을 구분합니다.

## 기존 사용자

기존 `ct_gist_id`, `ct_gist_token` 설정을 그대로 읽습니다. 브라우저에서 새로고침하면 새 화면이 열립니다. 새 기기는 연결 설정에 기존 비공개 Gist ID와 토큰을 입력하세요. 연결 전에는 공개 안내 목록만 표시합니다.

사용자 자료는 공개 저장소에 넣지 않습니다. 비공개 Gist의 `control_tower_registry_v4.json`이 최초 자료이며 편집은 `ct4_event_*.json`에 고유 변경 기록으로 추가합니다. 기존 `control_tower_catalog.json`과 같은 Gist의 다른 파일은 변경하지 않습니다.

같은 필드를 서로 다르게 바꾼 경우 충돌 화면에서 두 내용을 비교합니다. 전송 실패는 기기에 보관하고 다음 연결 때 재시도합니다. 연결 상태를 확인하고 기존 v3 화면이 열린 다른 기기는 새로고침하세요. 이전 브라우저에만 남은 미동기화 자료는 설정의 **이전 기기 자료 확인**으로 비교·병합할 수 있습니다.

## 자료 보관

- **JSON 백업 내보내기**는 시스템·문서·관계·점검을 포함하고 인증 토큰은 제외합니다.
- 가져오기는 차이를 보여준 후 변경 기록으로 병합하며 기존에만 있는 항목을 삭제하지 않습니다.
- 시스템 보관은 관리 목록의 표시 상태만 바꿉니다. 실제 프로그램·파일·서버에는 영향을 주지 않습니다.
- 로컬 경로는 복사해서 사용하고, http/https 접속 주소는 새 창으로 엽니다.
- 개인 계정 토큰을 공개 코드·메모·스크린샷에 기록하지 마세요. 토큰은 브라우저 로컬에 저장됩니다.

## 개발·배포

설치 패키지나 빌드가 필요 없는 HTML/CSS/ES modules입니다. `file://` 대신 로컬 HTTP 서버를 사용하세요.

```powershell
python -m http.server 8768 --bind 127.0.0.1
```

http://127.0.0.1:8768 접속. 종료는 Ctrl+C.

```text
npm run check
npm test
```

GitHub Pages는 main 브랜치의 루트에서 배포합니다. 개인 자료·토큰·비공개 Gist 스냅샷을 커밋하지 않습니다. 이전 버전은 Git 이력으로 복구할 수 있으며 기존 v3 Gist 파일도 보존됩니다.

변경 기록 파일은 자동 정리하거나 삭제하지 않습니다. 장기 사용으로 기록이 많아지면 백업한 뒤 별도 보존·압축 절차를 설계하세요.
